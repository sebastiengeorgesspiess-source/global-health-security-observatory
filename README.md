# Global Pathogen & Health Security Observatory 3.1.0

An open-evidence health-security dashboard by Sebastien Spiess.

Live application: https://sebastienspiess.ch/health/

Archived release: https://doi.org/10.5281/zenodo.22176516

The release separates observed country indicators, surveillance notices, health-system capacity and methodological limitations. It does not diagnose individuals, predict outbreaks or combine indicators into an opaque risk score. Missing data are retained as missing.

The archive contains application code, interface, derived public-data snapshot, methods and release metadata.
